# Nelix Launcher

Альтернативный модульный лаунчер для Minecraft. Основная задача проекта — объединить глобальные репозитории модов и локальные русскоязычные базы данных в одном интерфейсе, решив проблему доступности контента.

---

## 🛠 Основной функционал и интеграции

Большинство современных лаунчеров (Prism, MultiMC, ATLauncher) ограничены только западными API. Nelix Launcher решает эту проблему за счет одновременной работы с четырьмя источниками:

1. **Global API:**
   * **Modrinth API** — загрузка современных модов, плагинов и датапаков.
   * **CurseForge API** — доступ к классической и самой масштабной базе модификаций и готовых сборников.
2. **Local Web-Scrapers / API:**
   * **Ru-Minecraft** — интеграция для загрузки локализованных модов, старых редких карт и текстур, которые авторы не выкладывают на зарубежные сайты.
   * **Minecraft Island** — парсинг и загрузка специфичного контента, переводов и готовых сборок, отсутствующих в официальных репозиториях.

## ℹ️ Статус разработки и авторское право

Проект разрабатывается в гибридном формате. Я не заявляю, что весь исходный код написан мной вручную с нуля:

* **Генерация кода:** Рутинные задачи, базовая архитектура интерфейса и написание шаблонных HTTP-запросов к API делегированы нейросетям (ИИ).
* **Моя роль в проекте:**
  * Проектирование логики взаимодействия модулей лаунчера.
  * Интеграция и парсинг данных с Ru-Minecraft и Minecraft Island (налаживание стабильного получения файлов).
  * Проведение полного аудита безопасности кода, сгенерированного ИИ.
  * Тестирование работоспособности (QA), поиск утечек памяти (memory leaks), оптимизация сетевых запросов и закрытие уязвимостей.

## 🔒 Безопасность и конфиденциальность

Так как код лаунчера взаимодействует с игровыми аккаунтами, безопасность является приоритетом:
* **Авторизация:** Вход в лицензионные аккаунты реализован через официальный протокол Microsoft OAuth. Лаунчер не запрашивает, не обрабатывает и не сохраняет пароли пользователей в открытом виде.
* **Анализ утечек:** Все входящие и исходящие пакеты данных проверяются на предмет скрытой отправки телеметрии или логов. Код полностью прозрачен.
